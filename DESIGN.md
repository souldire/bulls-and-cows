# Bulls and Cows — DESIGN.md

## Структуры данных

| Что                         | Как храним                       | Зачем                                                                      |
| --------------------------- | -------------------------------- | -------------------------------------------------------------------------- |
| Секрет                      | строка                           | в строке ведущий ноль не теряется (`0123`), а в числе потерялся бы (`123`) |
| История попыток             | массив, дописывается через копию | каждый раз создаётся новый массив                                          |
| пул цифр в генераторе       | массив, цифра удаляется          | цифра выходит из пула, поэтому не может выпасть второй раз                 |
| проверка повторов в попытке | Set                              | закинул все цифры в Set: если его размер меньше длины строки — есть повтор |
